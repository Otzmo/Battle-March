# LinkButton

Umrandeter Link für externe Dokumente (PDF, Drive), der sich beim Hover `maroon` füllt.

- `border-piece` in `maroon`, `radius-4`, fett, .85rem. Pfeil `↗` vor dem Text markiert: öffnet in neuem Tab.
- Immer `target="_blank" rel="noopener noreferrer"`.
- Steht allein in einer eigenen Zeile, meist am Ende einer Version-Box oder eines Reiters.
