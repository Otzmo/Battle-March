# Callout

Vier Hervorhebungen für Text neben dem Fließtext – jede mit fester Rolle.

- **Statbox** (`bm-statbox`): weiß, 4px `maroon` links. Enthält ein Einheitenprofil (Kopfzeile mit `·`-getrennten Angaben + Profil-Tabelle).
- **Hinweis** (`bm-note`): `note-bg` mit `note-border`, .9rem. Nur für Geltungsbereich/Einschränkungen („For Games starting from 1000 pts.“).
- **Version** (`bm-version`): weiß, `maroon`-Rahmen mit 5px links. Oben „REV JJJJ-MM-TT · Version x.y.z“ fett in `maroon`, darunter Beschreibung, optional ein LinkButton.
- **Erklärung** (`bm-explainer`): `beige`, zentriert, .78rem – kurze Bedienerklärung über einem Werkzeug.
