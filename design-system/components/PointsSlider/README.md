# PointsSlider

Regler für das Punktelimit, der alle abhängigen Werte der Seite (Siegpunkte, Limits) live umrechnet.

- Weißer Kasten mit `maroon`-Rahmen und 5px linker Kante.
- Label in `maroon`, der aktuelle Wert fett; Endwerte darunter als `bm-ticks` (`ink-soft`).
- `accent-color: maroon`. Schritte folgen dem Spiel (Battle March 400–750 in 50er-Schritten, GermanComp 1000–3000 in 250er-Schritten).
