# Guide

Das Leitfaden-Blatt: ein Pergamentbogen (`beige`, `border-panel` in `maroon`, max. `sheet-max`) für Regeltext.

- Kapitel als nummeriertes `h1` („2. Gelände & Aufstellung“, bei GermanComp römisch „I.“) in `guide-h1` mit 3px `maroon`-Unterstrich.
- `h2`/`h3` ohne Farbe, nur Größe (`guide-h2`, `guide-h3`).
- Regelzitate und Aufstellungshinweise in `.italic`; Spielbegriffe und Werte **fett**.
- Enthält Tabellen (DataTable), Callouts und Akkordeons.
