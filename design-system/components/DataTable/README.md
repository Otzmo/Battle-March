# DataTable

Regeltabellen mit Haarlinien-Gitter (`grey-line`) und `tan`-Kopfzeile.

- **Standard**: Eigenschaften mit `·` getrennt in einer Zelle.
- **Profil** (`bm-table--profile`): Werteprofil B · KG · BF · S · W · LP · I · A · MW, Zahlen zentriert und tabellarisch, Name links. Fehlender Wert = `-`.
- **GermanComp** (`bm-table--gc`): Kopf in `maroon` mit weißem Text, erste Spalte fett, Prozente in `bm-pct` (`ink-faint`).
- Unter `bp-mobile` scrollt die Tabelle waagerecht in sich.
