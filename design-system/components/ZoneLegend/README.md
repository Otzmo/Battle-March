# ZoneLegend

Legende der Aufstellungszonen: eine Punktreihe für die Pinsel und Etiketten mit Tiefe und Abstand neben dem Brett.

- Zonenfarben: `zone-p1` (Spieler 1), `zone-p2` (Spieler 2), `zone-nml` (No Man's Land).
- Etikett: `beige`, `border-chip` in `maroon`, Titel VERSAL fett in `maroon`, Text `legend`.
- Auf dem Desktop stehen die Etiketten neben dem Brett auf Höhe ihrer Zone, mit gestrichelter Führungslinie (`has-leader`); mobil darunter, zwei pro Zeile, ohne Linie.
