# Button

Gefüllte `maroon`-Buttons für Aktionen, dazu Preset-, Pinsel- und Block-Varianten.

- **Standard**: `maroon`, weißer Text, `radius-4`, Schrift `control`; Hover `maroon-dark`. Ein Zustand „an“ (Zonen-Modus) bleibt in `maroon-dark`.
- **Erde** (`bm-btn--earth`, `earth`): nur für das Leeren/Zurücksetzen – setzt sich vom Maroon ab, ohne alarmierend zu wirken.
- **Preset** (`bm-btn--preset`): weiß mit `maroon`-Rahmen, füllt sich beim Hover. Beschriftung mit Nummer aus dem Leitfaden („1. Offene Feldschlacht“).
- **Pinsel** (`bm-btn--brush`): weiß, `control-border`-Rahmen, Farbpunkt davor; aktiv mit `maroon`-Rahmen und `shadow-brush-active`.
- **Block** (`bm-btn--block`): volle Breite, fett, 1rem – die eine Hauptaktion eines Reiters (Download). Deaktiviert: `disabled-bg`/`disabled-ink`.

Beschriftung: Verb oder Zustand, deutsch, Satzanfang groß („Zur Palette hinzufügen“, „Zonen-Modus: AUS“).
