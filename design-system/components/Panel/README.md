# Panel

Pergament-Kasten (`beige`, `border-panel` in `maroon`, `radius-4`) für Werkzeug-Bereiche im Kartenbau und in BASE.

- Titel als `h2` in `guide-h3`-Größe, `maroon`, mit `border-strong`-Unterstrich.
- Innenabstand `space-14` / `space-16`.
- Bedienhinweise darunter als `bm-hint` (kursiv, `ink-soft`).
- Panels stehen nebeneinander (Lücke `space-22`) und stapeln sich unter `bp-mobile`.
