## Änderungen

1. Jede Änderung zuerst im Artefakt OTZMO-TOW zeigen (die geänderte `index.html` dorthin veröffentlichen). Vorher nichts auf GitHub tun – kein Commit, kein Push, kein Branch, kein Pull Request.
